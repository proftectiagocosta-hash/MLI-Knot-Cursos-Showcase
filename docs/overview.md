# Overview / Visão geral

## What this repository is / O que este repositório é

**MLI-Knot-Cursos Showcase** is a public sanitized documentation repository derived from the current state of the private/local **MLI-Knot-Cursos** prototype.

It documents selected functional behavior without exposing private source code or unrevised development material.

O **MLI-Knot-Cursos Showcase** é um repositório público e sanitizado de documentação derivada do estado atual do protótipo privado/local **MLI-Knot-Cursos**.

Ele documenta comportamentos funcionais selecionados sem expor código-fonte privado ou material interno não revisado.

## Public value / Valor público

This showcase explains:

- the educational journey currently represented by the prototype;
- how local learner progress works;
- how sequential lesson access is represented;
- how study continuation is calculated;
- how certificate access relates to 100% completion;
- which certificate behaviors are prototype-only;
- which production capabilities do not yet exist;
- how the public/private boundary is maintained.

Esta vitrine explica:

- a jornada educacional atualmente representada pelo protótipo;
- como funciona o progresso local;
- como o acesso sequencial às aulas é representado;
- como a retomada de estudo é determinada;
- como o acesso ao certificado se relaciona à conclusão de 100%;
- quais comportamentos de certificado são apenas de protótipo;
- quais capacidades de produção ainda não existem;
- como é mantida a separação público/privado.
